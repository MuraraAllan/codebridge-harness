# React Principles

Choose the smallest applicable principle skill:

- Use `react-design-principle` for visual design, accessibility, responsiveness, and performance decisions.
- Use `react-developer-principle` for React architecture, composition, specialization, state, and abstraction decisions.
- Use `react-ux-principle` for navigation, feedback loops, and attention-focused interaction decisions.

Load more than one only when the task genuinely crosses those concerns.
