2. All Agent Hooks Lifecycle Events (hooks.json)Hooks trigger at specific stages of the agent lifecycle. You register them in your plugin/workspace hook configuration file:Event NameExecution PhaseCommon Customization Use Caseagent.onSessionStartWhen an agent chat session is initializedInject dynamic environment state, branch name, or database schemas into context.agent.onSessionEndWhen a session is closed or clearedCleanup temporary test containers or save session summaries.prompt.onSendImmediately before user prompt is sent to LLMSanitize sensitive data (PII, tokens) or attach workspace metadata.PreToolUseBefore a tool or terminal command executesValidate inputs, enforce security policies, or modify parameters.PostToolUseImmediately after a tool finishes executionAutomatically run linters/formatters, log audit trails, or run unit tests.Complete hooks.json Schema ReferenceJSON{
  "$schema": "https://raw.githubusercontent.com/microsoft/vscode/main/src/vs/workbench/contrib/chat/browser/schemas/hooks.schema.json",
  "hooks": {
    "agent.onSessionStart": [
      {
        "type": "command",
        "command": "powershell.exe",
        "args": ["-ExecutionPolicy", "Bypass", "-File", "${workspaceFolder}/.github/hooks/scripts/session-start.ps1"],
        "injectAsContext": true,
        "timeout": 15
      }
    ],
    "PreToolUse": [
      {
        "type": "command",
        "command": "node",
        "args": ["${workspaceFolder}/.github/hooks/scripts/guardrails.js"],
        "timeout": 10
      }
    ],
    "PostToolUse": [
      {
        "type": "command",
        "command": "npx",
        "args": ["prettier", "--write", "${file}"],
        "timeout": 30
      }
    ]
  }
}

4. MCP (Model Context Protocol) Integration (mcp.json)Connect external tools, databases, or local services via stdio or sse in .mcp/mcp.json:JSON{
  "mcpServers": {
    "local-filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "${workspaceFolder}"],
      "env": {
        "NODE_ENV": "development"
      }
    },
    "postgres-db": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "${env:DATABASE_URL}"]
    },
    "remote-api-service": {
      "url": "http://localhost:8080/mcp/sse",
      "transport": "sse"
    }
  }
}
5. All VS Code Terminal & Auto-Approve Settings (settings.json)This table covers every setting for controlling auto-execution, auto-approvals, and terminal behaviors:Setting KeyTypeDescriptiongithub.copilot.chat.terminal.enabledbooleanMaster toggle to enable terminal tool execution for agents.chat.tools.terminal.enableAutoApprovebooleanToggles command auto-approval evaluation.chat.tools.terminal.autoApproveobjectDictionary of command strings or regexes mapped to true (allow) or false (block/ask).chat.tools.global.autoApprovebooleanEnables full auto-approval for non-destructive commands across all tools.chat.tools.terminal.terminalTimeoutnumberMax execution time (in ms) for terminal commands before cancellation.github.copilot.chat.codeGeneration.useInstructionFilesbooleanEnables automatic loading of .github/copilot-instructions.md.Full Production settings.json TemplateJSON{
  // Master Feature Toggles
  "github.copilot.chat.terminal.enabled": true,
  "github.copilot.chat.codeGeneration.useInstructionFiles": true,

  // Tool Auto-Approval Rules
  "chat.tools.terminal.enableAutoApprove": true,
  "chat.tools.terminal.autoApprove": {
    // Harness and testing scripts
    "powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\\tests\\run-harness.ps1": true,
    "/^powershell(\\.exe)? .*\\\\tests\\\\.*/i": true,

    // Development utilities
    "/^npm (test|run|start|ci).*/": true,
    "/^git (status|diff|log|branch).*/": true,

    // Block destructive operations
    "rm": false,
    "del": false,
    "rmdir": false,
    "/^git push.*/": false,
    "/^Remove-Item/i": false
  },

  // Execution & Timeout Guards
  "chat.tools.terminal.terminalTimeout": 60000
}
