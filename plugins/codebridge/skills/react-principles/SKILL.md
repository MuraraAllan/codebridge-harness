# React Principles

Choose the smallest applicable principle skill:

- Use `design-principle` (or `react-design-principle`) for visual design, accessibility, responsiveness, and performance decisions.
- Use `react-javascript-typescript` (or `react-developer-principle`) for React, JavaScript, and TypeScript architecture, composition, specialization, state, and abstraction decisions.
- Use `ux-principle` (or `react-ux-principle`) for navigation, feedback loops, and attention-focused interaction decisions.

Load more than one only when the task genuinely crosses those concerns.
